# Baldaworks workspace

This repository pins the Balda and Knowl revisions used in this workspace. Keep shared workspace procedures in `docs/runbooks/`.

For product changes, follow the project's own instructions in [balda/AGENTS.md](projects/balda/AGENTS.md) or [knowl/AGENTS.md](projects/knowl/AGENTS.md). Run its tools from that project directory. Publish the product commit before recording its new submodule pin here.

See the [workspace runbook](docs/runbooks/workspace.md) for checkout, verification and pin updates.
